## Lista emuladores
adb devices

## Abrir o emulador
~/Android/Sdk/emulator/emulator -avd Medium_Phone

## Roda o emulador
cordova emulate android

## Roda no browser
cordova run browser

## Muda o packge
cordova config set packageName br.com.davidsousadev.myapp
